# Alkemyo builds

This repository only holds packaged Alkemyo development builds and the signed update feed that the app's **Settings > Updates** page reads. It contains no source code.

Each release has the macOS and Windows ZIPs, their `.sha256` files, and a manifest signed with the Alkemyo update key. The app refuses any update whose signature, size or SHA-256 does not match.

These are development builds, not a product release.
